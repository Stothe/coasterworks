# Coasterworks roadmap to "Steve can play"

Spec: `docs/superpowers/specs/2026-10-16-coasterworks-design.md`. Phases 0 and 1 of the spec, split into plans that each produce working, tested software. Plans are written one at a time, each against the code the previous one landed, so names and paths in later plans are exact.

| # | Plan | Delivers | Depends on |
|---|------|----------|------------|
| A | `2026-10-16-a-foundation.md` | Monorepo, sim core (world, terrain, time, fixed-point RNG), command registry with undo and log, queries, save/load, golden determinism test, CLI headless run, MCP server over stdio and HTTP, CI | nothing |
| B | `b-renderer-and-shell.md` | `packages/protocol` SimHost messages and binary snapshots, `packages/render` (three.js terrain, lighting, camera, picking), `apps/web` Vite app showing a park, sidecar `coasterworks serve`, `apps/desktop` Tauri Mac app with the sidecar bundled | A |
| C | `c-ui.md` | `packages/ui`: dock, tray, inspector, status pills, command bar, toasts, undo wiring, terrain brush UI | B |
| D | `d-park-life.md` | Paths and queues, park entrance and fee, guests (needs, pathfinding, queueing, buying, thoughts, leaving), flat rides and stalls from `packages/content`, ride operation, finances with monthly roll-up | A, C for UI |
| E | `e-coaster.md` | Track model and families, draw-mode builder, physics, ratings, generated track geometry and supports, test runs, `.track` files, `coaster_build_from_points` | B, C, D |
| F | `f-assistant.md` | `packages/assistant` provider interface, Claude Code provider via Agent SDK, assistant panel with streamed actions and per-message checkpoint undo, MCP attach proxy | A, C |
| G | `g-release.md` | GitHub repo public, README with clips, web demo on Pages, signed-if-possible `.dmg`, CONTRIBUTING, v0.1 tag | all |

"Steve can play" is the end of D plus E in the Mac app from B and C. F and G follow. Decisions made while planning that refine the spec are recorded in each plan's header under "Spec refinements"; the spec is updated when a plan lands.
